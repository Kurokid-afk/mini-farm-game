# UU田园合集

一款把深度种菜、像素宠物园、连连看、消消乐和田园合成接入同一经营循环的像素游戏，提供 Windows 桌面版和原生 Android 竖屏版。

## 联动循环

- 农场收获会产出阳光，用于小游戏中的提示、重排、减速和清障。
- 连连看产出种子券，可在集市兑换当前等级的种子。
- 消消乐与田园合成都产出订单印章，自动让下一次顾客订单增加 25% 金币。
- 连连看和消消乐为无倒计时、无步数的持续玩法，达成短里程碑后立即结算并继续。
- 田园合成为按分数结算的单局玩法：达到 2048 后仍可继续，只有棋盘无路可走时结束并发放对应档位奖励。
- 每领取三次普通小游戏奖励，还会获得轮换游园礼袋：金币、阳光或三种经营物资。
- 丰收庆典分别累计连连看配对和益智屋消除/合成数量；每轮目标会变化，完成后奖励金币和永久研究星，并立即开启下一轮。

## 农场深度

- 六种作物具有约 2、4、7、12、20、30 分钟的不同成熟时间、成本、产量和解锁等级。
- 浇水、堆肥、沃土、作物熟练度和地标共同影响速度、产量与品质。
- 同一地块改种另一种作物会触发轮作加成：成熟时间缩短 10%，收获品质提高。
- 顾客订单直接显示在农场，并保证奖励能够支撑后续订单备货。
- 金币可用于扩建土地、升级水壶、菜篮、温室、集市和永久地标。
- 洒水器与收菜助手按台购买，每台只能自由布置到一块土地，并可分别暂停或开启。
- 自动化设备拥有巡逻、移动、喷水、机械臂收获和装箱动画。

## 像素宠物园

- 用农场收入购买地契，依次领养小麦犬、橘子猫、云朵兔和团子鸡。
- 四种动物均有待机、行走、吃饭、玩耍、洗护和睡觉的完整全身像素贴图。
- 小狗、猫、兔子和小鸡采用不同活动路线与休息节奏；互动时会先走到对应设施，再切换动作贴图并返回。
- 同一只宠物一次只执行一个动作，动作期间锁定其他互动和切换，避免状态覆盖与贴图错乱。
- 宠物粮由农场仓库中的蔬菜加工；饱食度直接影响访客收入，种田是宠物园的持续供给来源。
- 可购买小屋、水池、自动喂食机、玩具箱和护理台，关闭游戏后状态与收益仍会结算。
- 领取访客收入时可回收少量堆肥，重新用于农田，形成蔬菜、宠物、金币与肥料的循环。
- 小屋、水池、喂食机、护理台以及六种装饰均使用统一的精致像素物件，并真实布置在场景中。
- 宠物心情、饱食与洁净共同影响访客收入；自动化负责维持状态，但不会完全替代互动。
- 动物与设施统一缩小并分散到草地边缘，宠物状态集中显示在右侧领养卡，活动区不再被状态条遮挡。
- 草地、设施和动物统一使用大颗粒像素密度，避免素材画风和比例互相冲突。

## 桌面功能

- 窗口可自由缩放，并支持一键置顶。
- 最小化后进入系统托盘。
- 作物关闭游戏后继续成长，存档保存在本机。
- 主操作区、辅助图鉴和奖励信息使用明确的尺寸层级；同排面板共用边界，缩小窗口时文字仍保留内边距。
- 退出时会保存当前页面、已种作物、自动化、宠物状态以及三种小游戏的完整残局；再次打开会回到原来的进度。
- 升级 EXE 时沿用原应用标识和存档键，不会清空已有金币、农田或小游戏棋盘。
- Windows 发布同时提供完整游戏 EXE 和独立更新器 EXE：新用户直接运行完整游戏，老用户退出游戏后运行更新器。
- 更新器会优先读取上次运行路径，再搜索更新器同目录、桌面、下载、文档和固定磁盘；自动查找失败时可手动选择旧版 EXE。
- 更新过程只替换程序文件，使用临时文件与备份回滚保护，不访问或删除本地存档目录。
- 按 `F` 切换全屏，按 `Esc` 退出全屏。

## Android 版本

- 使用 Android 原生 `Canvas`、触控事件和 `SharedPreferences` 独立实现，不使用 WebView，也不打包网页文件。
- 所有玩法、像素动物、宠物园背景和设施素材均随 APK 本地安装，不需要联网或额外下载资源。
- 使用同一套经营、奖励、动画和本地存档规则；界面读取状态栏、刘海与底部手势区后，按实际安全区域自适应填满竖屏。
- 顶部资源和底部导航固定，农田、棋盘与宠物草地吸收可用高度；商店列表保持紧凑，不再把控件均匀拉散。
- 全局正文、数值、按钮和棋盘标签采用分级移动端排版，长按钮文字会在边界内自动适配，小标签不再统一加粗。
- 页面统一使用浅薄荷背景、白色信息面和细灰绿边线；标题、主操作、辅助信息与禁用状态保持固定层级，不用厚重描边堆叠内容。
- 顶部按当前页面只显示三项相关资源，五个主要入口固定在底部，避免六种库存同时抢占注意力。
- 农田使用独立像素场景、木框土畦和扩建木牌；只显示已开放土地与下一块入口，不再用巨大灰色方格表现后续锁定土地。
- 扩建木牌拥有独立点击逻辑，选中播种、浇水、施肥或设备后仍可直接扩建；成熟作物可直接点击收获。
- 集市、宠物领养、设施和装饰使用分页陈列，避免在小屏幕堆叠。
- 田园合成使用手机原生滑动操作，不显示桌面式方向按钮。
- APK 最低支持 Android 7.0；覆盖安装沿用原包名和存档，关闭应用后会恢复农田、当前页面与全部小游戏残局，并继续结算作物、宠物状态和访客收益。

## 动画反馈

- 播种、浇水、施肥、成熟、收获、订单、出售、购买和解锁均有独立反馈；短提示显示在标题空白区，不遮挡土地、按钮或底部信息。
- 自动洒水器、收菜机器人、宠物设施和场景装饰拥有持续运作动画。
- 连连看包含选中呼吸、错误抖动、路径流光、配对弹出、碎光和连击浮字。
- 连连看的十种牌使用不同轮廓、配色和中文名称，不依赖细小角标辨认。
- 连连看恢复存档时会校验每种图案数量；发现旧版孤张会自动补成一对，无可连组合会自动重排。
- 消消乐包含交换滑动、无效回弹、消除爆开、连续掉落、补位和重排过渡。
- 消消乐的八种棋子同时使用不同颜色、轮廓和中文单字，每轮上场七种，目标区与棋盘按统一网格对齐。
- 田园合成包含滑动、合并弹性和出生缩放；同一次滑动中每个方块最多合并一次，堵盘后显示本局得分与金币、印章、阳光奖励。
- 动画播放期间会短暂锁定棋盘输入，防止连续点击造成误操作。

## 构建与测试

```powershell
npm install
npm run test:logic
npm run test:android-logic
npm run test:e2e
npm run test:mobile
npm run build
npm run build:updater
npm run test:updater
powershell -ExecutionPolicy Bypass -File scripts\build-android.ps1
powershell -ExecutionPolicy Bypass -File scripts\verify-android-apk.ps1
```

Windows 完整游戏输出到 `release/UU-Farm-Windows.exe`，老用户更新器输出到 `release/UU-Farm-Updater.exe`，Android 安装包输出到 `release/UU-Harvest-Mobile.apk`。APK 验证脚本默认执行覆盖安装，保留设备现有进度，再检查冷启动、主要页面切换、种植、重启存档和崩溃日志；只有显式传入 `-CleanInstall` 才会卸载旧版。
