# UU田园合集

一款把深度种菜、连连看、祖玛和消消乐接入同一经营存档的桌面像素游戏。

## 联动循环

- 农场收获会产出阳光，用于小游戏中的提示、重排、减速和清障。
- 连连看产出种子券，可在集市兑换当前等级的种子。
- 祖玛产出堆肥与品质祝福，让下一批收获更值钱。
- 消消乐产出订单印章，自动让下一次顾客订单增加 25% 金币。
- 三种小游戏各通关一次会举办丰收庆典，奖励金币和永久研究星。

## 农场深度

- 六种作物具有不同成熟时间、成本、产量和解锁等级。
- 浇水、堆肥、沃土、作物熟练度和地标共同影响速度、产量与品质。
- 顾客订单直接显示在农场，并保证奖励能够支撑后续订单备货。
- 金币可用于扩建土地、升级水壶、菜篮、温室、集市和永久地标。
- 洒水器与收菜助手按台购买，每台只能自由布置到一块土地。
- 自动化设备拥有巡逻、移动、喷水、机械臂收获和装箱动画。

## 桌面功能

- 窗口可自由缩放，并支持一键置顶。
- 最小化后进入系统托盘。
- 作物关闭游戏后继续成长，存档保存在本机。
- 按 `F` 切换全屏，按 `Esc` 退出全屏。

## 动画反馈

- 连连看包含选中呼吸、错误抖动、路径流光、配对弹出、碎光和连击浮字。
- 消消乐包含交换滑动、无效回弹、消除爆开、连续掉落、补位和重排过渡。
- 动画播放期间会短暂锁定棋盘输入，防止连续点击造成误操作。
